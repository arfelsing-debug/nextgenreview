# Bilingual Content Rules

English and Czech are equal product versions.

## Rules

- Question IDs, dimension IDs, scoring and diagnostic rules are language-neutral.
- No scoring logic may depend on translated text.
- Every participant-facing string must exist in both languages before release.
- Czech is an adaptation for natural professional Czech, not a literal machine translation.
- Amendments to substantive meaning require review of both language files in the same development cycle.
- Reports generated in either language must use the same underlying response data and diagnostic result.
- The participant's selected language is stored independently from response values.

## Terminology review

Before public testing, Czech terminology should receive a native professional-language pass, particularly for fiduciary, governance, trust, beneficiary, ownership and board terminology where English concepts do not always map neatly onto Czech institutional usage.
